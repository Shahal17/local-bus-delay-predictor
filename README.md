# Local Bus Delay Predictor

A beginner-friendly end-to-end machine learning project that predicts the expected delay of a local bus from operating conditions.

The idea comes from a practical problem: passengers on local routes often do not know whether a bus will arrive on time, especially where live GPS tracking is unavailable.

## What the project demonstrates

- reproducible data generation
- feature engineering
- preprocessing with scikit-learn pipelines
- regression model comparison
- MAE, RMSE and R² evaluation
- saving the best model
- predicting delay for a new trip from the command line

## Inputs

- route distance (km)
- number of stops
- departure hour
- rainfall (mm)
- traffic level: low / medium / high
- day type: weekday / weekend
- peak-hour indicator

Target: `delay_minutes`

## Dataset

The first version uses **synthetic data** generated by `src/generate_data.py`. The generation rules are deliberately visible so the experiment is reproducible.

This is not real Kerala bus data and should not be used for operational decisions. A future version can replace it with actual scheduled and observed arrival timestamps.

## Setup

```bash
python -m venv .venv
pip install -r requirements.txt
python src/generate_data.py
python src/train.py
```

Then try a prediction:

```bash
python src/predict.py --distance 18 --stops 12 --hour 17 --rain 4 --traffic high --day weekday
```

## How model selection works

The training script compares a Linear Regression baseline with a Random Forest Regressor. Both use the same train/test split and preprocessing. The model with the lowest test MAE is saved to `models/bus_delay_model.joblib`.

## Why keep it small?

This repository is intended as a readable code sample. The goal is to make the reasoning, preprocessing, model comparison and limitations easy to inspect rather than hide them behind a large application framework.
